## 1. Project Overview

This project explores how Google Photos can improve photo discovery for users who remember the context of a photo but cannot recall its exact date, location, album, or keywords.

The proposed solution, **Memory-Guided Retrieval**, enables users to describe a photo using incomplete memories and retrieve relevant photos through AI-assisted search and refinement.

The project covers market and product analysis, user research, problem validation, solution prioritisation, MVP definition, and prototype development.

## 2. Problem Statement

Users often remember photos through contextual clues such as:

- A place they visited.
- A person or occasion.
- An approximate time or event.
- Visual details or activities.
- An incomplete description of the moment.

However, traditional search can become difficult when users cannot remember exact dates, locations, names, or keywords.

**How might we help users retrieve photos using incomplete memories instead of requiring exact search details?**

## 3. Research & Discovery

The discovery process combined public product feedback analysis and primary user research.

### Research Highlights

- Analysed 1,000 public feedback signals.
- Identified 66 retrieval-relevant signals.
- Grouped findings into 4 problem clusters.
- Collected 22 survey responses.
- Conducted 6 user interviews.
- Identified 4 behavioural user segments.
- Evaluated solution opportunities using RICE prioritisation.

### Key Research Focus

- Photo discoverability.
- Search limitations.
- Memory-based retrieval behaviour.
- User expectations from AI-powered search.
- Friction when searching with incomplete information.

## 4. Product Strategy & Solution Prioritisation

Three solution directions were evaluated:

1. Smart Voice Suggestions
2. Adaptive Voice Mode
3. Memory-Guided Retrieval

The selected direction was **Memory-Guided Retrieval**, focused on helping users find photos through natural descriptions and contextual memories.

## 5. Proposed Solution – Memory-Guided Retrieval

The proposed experience allows users to describe a remembered moment in their own words.

### Core Workflow

1. **Memory Input:** User describes the photo or moment they remember.
2. **Clue Extraction:** AI identifies relevant people, places, occasions, time clues, and visual details.
3. **Candidate Retrieval:** The system finds potentially relevant photos.
4. **Refinement:** Users refine results using additional contextual clues.
5. **Photo Retrieval:** Users identify and access the relevant photo.

## 8. Product Success Metrics

The proposed product experience can be evaluated using:

- Successful Photo Retrieval Rate.
- Search-to-Photo Retrieval Time.
- Search Refinement Rate.
- Search Abandonment Rate.
- User Satisfaction with Retrieved Results.

These are proposed success metrics, not measured production results.

## 9. Expected Product Impact

The proposed solution aims to:

- Reduce friction in finding old or difficult-to-remember photos.
- Make photo discovery more natural and context-driven.
- Reduce dependence on exact dates and keywords.
- Improve the overall photo retrieval experience.

## 10. Project Status & Disclaimer

This is an independent Product Management case study and prototype project.

The proposed solution is not an officially implemented Google Photos feature. The MVP demonstrates the concept using a controlled demo photo library and does not represent a production integration with Google Photos.
